# data-science-portfolio

Source files for my **data science portfolio website**, published for free with **GitHub Pages**.

**Live site:** https://Erik0380.github.io/data-science-portfolio/

## How it works

- `index.md` — the website content (name, introduction, skills, and a project showcase). GitHub Pages builds it as the site's home page with Jekyll.
- `solar_cost_collapse.png` — the visualization featured in the project showcase.
- `_config.yml` — site settings (title, description, theme).

Any commit to the `main` branch is rebuilt and published automatically by GitHub Pages.
